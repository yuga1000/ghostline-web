## Очистка кеша браузера

После удаления pet.js необходимо:

1. **Chrome/Edge:**
   - Открыть DevTools (F12)
   - Правый клик на кнопке Reload
   - Выбрать "Empty Cache and Hard Reload"

2. **Firefox:**
   - Ctrl+Shift+R (Windows/Linux)
   - Cmd+Shift+R (Mac)

3. **Safari:**
   - Cmd+Option+E (очистить кеш)
   - Затем Cmd+R (перезагрузить)

---

## Проверка после очистки

1. Откройте stream.html в браузере
2. Откройте DevTools Console (F12)
3. Убедитесь что нет ошибок связанных с pet.js
4. Проверьте что пет загружает состояние из localStorage:
   ```
   [Pet] Loaded state - Logs: X, Stage: Y
   ```

---

## Тестирование новой системы

### Проверка persistence:
1. Откройте stream.html
2. Дождитесь нескольких логов (пет должен проснуться)
3. Обновите страницу (F5)
4. Пет должен сохранить свой logCount и stage

### Проверка debouncing:
- Логи приходят быстро -> пет НЕ должен дергаться на каждый лог
- Только важные логи (с ключевыми словами) вызывают анимацию

### Проверка визуального роста:
- При достижении 10, 25, 50 логов пет должен "мигать" и расти
- Показывается сообщение "Growing up! Stage X"
