## 🕷️ БОЛЬШАЯ ИДЕЯ: Эволюция Agent Pet - Универсальный живой организм

### Концепция: Мимикрирующее существо

Пет не просто статичный персонаж - это **живое существо которое эволюционирует и мимикрирует**!

### Режимы существования:

#### 1. 🕷️ Режим Паука-Скакунчика
**Поведение:**
- Прыгает по сайту дискретными скачками (8fps)
- **Охотится на зеленые пиксели** (элементы с `color: #00ff00`)
- Выслеживает: кнопки, текст, иконки с зеленым цветом
- Прыжок → замирание → оценка → новый прыжок
- **Атака:** быстрый прыжок на цель, "съедает" (пиксель тускнеет/исчезает)

**Паутина:**
- Иногда (15% времени) переходит в режим паука-строителя
- Плетет паутину между элементами страницы
- SVG линии между точками крепления (дискретные, step-end анимация)
- Ловит зеленые пиксели в паутину
- Съедает пойманные пиксели

**Визуал:**
- 8 ног вместо 4
- Глаза увеличиваются (охотничий взгляд)
- Цвет: черный/темно-серый с зеленым отблеском

#### 2. 🐸 Режим Лягушки
**Поведение:**
- Сидит неподвижно (затаился)
- Дышит (раздувает бока)
- **Язык-выстрел:** длинный язык выстреливает к цели (зеленый пиксель)
  - Дискретная траектория (step-end)
  - Захват пикселя
  - Втягивание обратно
- Может прыгать (как лягушка) - дуга траектория

**Визуал:**
- Приседает низко к земле
- Широкое тело, выпученные глаза
- Цвет: зеленый с темными пятнами

#### 3. 🦎 Режим Хамелеона
**Поведение:**
- **Мимикрия под фон:** принимает цвет окружающих элементов
  - Берет цвет родительского элемента
  - Плавно меняет оттенок (дискретно по палитре)
- Медленно двигается по странице
- Глаза двигаются независимо (каждый отдельно)
- Язык как у лягушки (длинный, липкий)

**Визуал:**
- Удлиненное тело
- Закрученный хвост (спираль из пикселей)
- Цвет: адаптивный (берется из CSS background)

#### 4. 🐙 Режим Осьминога
**Поведение:**
- Плавает по странице (волнообразное движение)
- **8 щупалец** которые двигаются независимо
- Меняет цвет (как хамелеон) но быстрее
- Может "чернила" выпустить - темное облако пикселей
- Щупальцами хватает зеленые элементы

**Визуал:**
- Круглое тело (голова)
- 8 щупалец разной длины
- Цвет: меняется от оранжевого до синего и фиолетового
- Пульсация (дыхание через жабры)

#### 5. 🌸 Режим Растения (уже есть)
**Текущее состояние:** Во время rest/cooldown
- Рост ног (корни)
- Раскрытие рук (листья)
- Доп глаза и антенны

---

### Система выбора режима:

**Триггеры:**
1. **Время суток:**
   - День (6:00-18:00): Паук-скакунчик (активная охота)
   - Вечер (18:00-22:00): Лягушка (затаился)
   - Ночь (22:00-6:00): Осьминог (плавает в темноте)

2. **Активность на странице:**
   - Много зеленых элементов → Паук (много добычи)
   - Мало активности → Хамелеон (прячется)
   - Cooldown → Растение (отдыхает)

3. **Случайность:**
   - 20% шанс случайной трансформации каждые 10 минут
   - Анимация превращения (discrete morphing)

---

### Взаимодействие с пользователем:

#### Пассивное:
1. **Реакция на курсор:**
   - Следит глазами за мышкой
   - Если курсор близко → пытается поймать (думает что еда)
   - Пугается быстрых движений

2. **Реакция на скролл:**
   - Держится на экране (не уходит за границы viewport)
   - При скролле "цепляется" за элементы

3. **Клик по зеленому элементу:**
   - Пет видит "вспышку" и прыгает туда
   - Проверяет - можно ли съесть

#### Активное:
1. **Клик по пету:**
   - **1 клик:** Внимание (поворачивается)
   - **2 клика:** Виляет / машет
   - **3 клика:** Танцует
   - **Долгий зажатый клик:** Гладишь → мурлычет (вибрация пикселей)

2. **Перетаскивание (drag):**
   - Можно взять пета и перенести
   - Сопротивляется (немного дергается)
   - Когда отпускаешь - возвращается к охоте

3. **Кормление:**
   - Двойной клик по зеленому элементу → "подсветить как еду"
   - Пет прыгает и съедает
   - Довольный танец после еды

4. **Игры:**
   - "Лазерная указка" - курсор оставляет след из зеленых точек
   - Пет гоняется за ними
   - Можно рисовать паттерны - пет повторяет траекторию

#### Процесс охоты:
1. **Обнаружение** → глаза фокусируются на цели
2. **Выслеживание** → медленно приближается
3. **Подготовка** → приседает (у паука/лягушки)
4. **Атака** → прыжок/выстрел языком (8fps discrete jump)
5. **Поедание** → жевательная анимация, цель тускнеет
6. **Сытость** → ленивые движения, может поспать

#### Состояние сытости:
- **Голодный (0-30%)**: активная охота, быстрые движения
- **Нормальный (30-70%)**: умеренная активность
- **Сытый (70-100%)**: ленивый, больше отдыхает
- **Переел (100%+)**: может "икать" пикселями

```javascript
// Создает SVG паутину между точками
function createWeb(startPoint, endPoint) {
  const svg = document.createElementNS('http://www.w3.org/2000/svg', 'svg');
  const line = document.createElementNS('http://www.w3.org/2000/svg', 'line');

  // Discrete animation - появление паутины по сегментам
  animateWebLine(line, startPoint, endPoint, 8); // 8fps

  // Прикрепляется к элементам страницы
  attachToElements([startPoint, endPoint]);
}
```
