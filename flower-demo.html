🌸 FLOWER ANIMATION - РАСТЕТ ПО ПИКСЕЛЯМ

Как работает анимация цветка:

  • ВАЖНО: Никакого scale! Только HEIGHT меняется у ног (8px → 24px)
  • Фазы 1-2: Тело поднимается вверх (translateY: 0 → -4px)
  • Фаза 3: Появляется ПЕРВЫЙ РЯД короны цветка! (Row -1) + ноги 12px
  • Фаза 4: Появляется ВТОРОЙ РЯД короны! (Row -2) + ноги 16px + ветки
  • Фаза 5: Появляется ТРЕТИЙ РЯД короны! (Row -3) + ноги 20px
  • Фаза 6: Полное цветение! Огромная корона + ноги 24px + глаза прямоугольные

⬇️ Смотри анимацию ниже - 12-секундный цикл роста!

🌸 АНИМИРОВАННЫЙ ЦВЕТОК

⬆️ Смотри как:
• Тело поднимается вверх (translateY)
• КОРОНА ЦВЕТКА растет! (3 ряда пикселей появляются сверху по очереди)
• Ноги растут по HEIGHT (8px → 12px → 16px → 20px → 24px)
• Ноги раздвигаются в стороны (translateX)
• Руки превращаются в ветки (width растет)

12-секундный цикл, полностью БЕЗ SCALE!
Новые пиксели добавляются как в твоих референсах!
