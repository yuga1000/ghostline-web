# GHOSTLINE Pixel Data

Эта папка для хранения экспортированных JSON файлов из pixel editor.

## Workflow:

1. Нарисовать в **pixel-editor.html**
2. Ввести имя (например: `spider`, `cat`, `flower`)
3. Нажать **💾 Save Code File**
4. Файл скачается в **Downloads**
5. Переместить файл сюда (`pixel-data/`)
6. Claude возьмет отсюда код и вставит в pet!

## Файлы:

- `spider-*.json` - паук
- `cat-*.json` - кот
- и т.д.
